00 / INITIAL CONDITION

An initial state, not a conclusion.

We begin with a unit vector in three-dimensional space. No measurement outcome has been selected yet. The drawing shows possible directions for updating this state.

‖ψ₀‖ = 1

A geometric example, not a validated account of human meaning.

01 / FIRST UPDATE

A question selects a direction.

We select the affirmative outcome of a rank-one projector onto a line. After normalization, the new state lies in that subspace.

Q = |u⟩⟨u|, u = (0.8, 0, 0.6)

The stated probability refers to this specific outcome; the transition is not guaranteed.

02 / SECOND UPDATE

The plane changes what remains.

A second projector is applied, now onto a plane that does not contain the line. The new state lies in the plane and the diagram provides the visual impact.

P = diag(1, 1, 0)

Because line and plane are not nested, the second projection actually changes the state.

Joint probability for this sequenceQ → P : 0.4778
03 / DISSOLUTION

A representation is not an explanation.

At the end of the sequence, the drawing disperses. This is a narrative device, not a physical process in which a vector disappears. What matters is the prediction and its alternatives.

PQ ≠ QP

Reversing the order yields a different joint probability; both calculations are shown below.

Formal example in ℝ³: orthogonal projectors and state updates conditioned on observing the “yes” outcome twice. These are not experimental psychological data.

In this example, Pr(Q → P) = 0.4778 and Pr(P → Q) = 0.2304 for the “yes, yes” outcomes. These are sequential joint probabilities.

Dissolving the drawing is not a third mathematical operation: it only closes the illustration.
